⚡ Quick Start Guide

Get your game running in 5 minutes

1
Admin: Create questions and set up the room
2
Host: Share room code (or QR code) with players
3
Players: Join via code and enter names
4
Host: Click "Start Game" and begin quiz
5
FOH: Display questions and celebrate winners
