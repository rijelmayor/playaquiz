# DW AdSign CRM V12.2.1 Implementation

## Included

- Admin-controlled commission defaults: Percentage or Fixed Amount.
- Existing commission rows remain job-specific snapshots.
- Automatic commission creation for new jobs.
- Automatic commission recalculation when `jobs.final_value` changes.
- Sales quotation create/edit/revision workflow.
- Quotation discount: none / percentage / fixed.
- Quotation additional notes/comments.
- Quotation version history; previous versions are superseded, not overwritten.
- Admin quotation editing and approval queue.
- DW quotation PDF styling using the logo's charcoal / blue / teal / gold palette.
- Gmail SMTP quotation sending via Nodemailer.
- Customer completion acknowledgment form.
- Design revision notes, filenames, approval metadata.
- Admin audit trail for jobs, quotations, commissions, designs, acknowledgments and commission settings.
- Sales are prevented at the database level from accepting/rejecting quotations; Admin controls acceptance/rejection.

## Supabase migration

For the current database, run:

`supabase/migrations/0020_v12_2_1_workflow_completion.sql`

The existing 0015-0018 migrations remain unchanged.

The 0019 migration in this package is also corrected so its commission trigger references a function that exists before the trigger is created.

## Gmail / Vercel

The application reads:

- `SMTP_HOST=smtp.gmail.com`
- `SMTP_PORT=465`
- `SMTP_SECURE=true`
- `SMTP_USER=<Gmail address>`
- `SMTP_PASS=<Google App Password>`
- `SMTP_FROM=<Gmail address>`

These must be configured in Vercel Environment Variables for Production/Preview as needed. Never commit the App Password to GitHub or the project ZIP.

## End-to-end verification

1. Admin opens Commission Settings and saves Percentage or Fixed Amount.
2. Create a new job and confirm one `job_commissions` row is created using the current Admin default.
3. Set a job's `final_value`; confirm the commission amount recalculates.
4. Sales creates a quotation, applies an optional discount, and adds customer-facing notes.
5. Sales edits/revises the quotation; confirm a new version is created and the old version becomes `superseded`.
6. Download the PDF and confirm DW logo/brand palette, totals, discount and notes.
7. Send the quotation to a test Gmail address and confirm receipt + PDF attachment.
8. Admin accepts the quotation from the approval queue.
9. After installation, Admin completes the acknowledgment form.
10. Review Admin audit trail for quotation, job, commission, design and acknowledgment changes.
